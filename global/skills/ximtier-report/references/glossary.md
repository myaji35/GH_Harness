# 현업 어휘 번역 원칙 + 용어 대조표


**원칙 3**: ①기술어는 본문 0회, 부록 A에만(게이트로 grep 검사) ②번역은 은유가 아니라 판단 기준을 담은 문장 ③기획자 원문 인용은 번역하지 않는다 — 그 문장이 곧 현장어(§5-G).

| # | 기술어 | 현업어 |
|---|---|---|
| 1 | Y변수/Target Y | 성과지표(예: 공수효율) |
| 2 | X변수 | 관리·환경 요인 |
| 3 | 통제가능 변수 | 우리가 조절할 수 있는 손잡이(관리 레버) |
| 4 | 통제불가 변수 | 주어진 조건(날씨·시황·공급) |
| 5 | Reverse What-if | 목표 역산 — 목표를 찍으면 조건을 거꾸로 계산 |
| 6 | What-if | 조건 바꿔보기 시뮬레이션 |
| 7 | R² | 설명력 — 성과 변동의 몇 %를 설명하는가(상/중/하 병기) |
| 8 | feature importance | 성과 기여도 순위 |
| 9 | 인과계수 | 1단위 움직일 때 성과가 변하는 폭 |
| 10 | 의사결정트리 | 성과의 갈림길 지도 |
| 11 | 지식그래프 | 변수 관계망 지도 |
| 12 | ERD | 데이터 지도(테이블 관계도) |
| 13 | 미션SQL | 질문→추출 — 말로 물으면 데이터로 답 |
| 14 | 5P 분류 | 성과·운영·투자·신호·환경 다섯 축 정리 |
| 15 | 데이터 누수 | 답안지 베끼기 오류 — 성과로 성과를 예측하는 반칙 |
| 16 | 카티전 곱/행수 폭발 | 데이터 중복 결합 오류(뻥튀기) |
| 17 | 5분위(quintile) | 상·중·하위 20% 구간 비교 |
| 18 | baseline | 현재 수준(기준선) |
| 19 | 처방 이행도 | 지시 대비 실행률 |
| 20 | 합성 데이터 | 모의 데이터 — 정답을 심어둔 시험지 |
| 21 | 트리거 시뮬레이션 | 조기경보 — 사건이 번지는 길목 |
| 22 | 과적합 | 기출문제 암기 — 새 달에는 안 맞는 모델 |
| 23 | P0/P1 · ISS-NNN | **고객 문서 표기 금지** — "즉시조치/차기조치", 이슈번호는 내부 부속서 전용 |
| 24 | validated/dataset 등록 | 검증 통과 / 분석 대상 확정 |



## 산업별 어휘 (누적 자산)

### 조선업

| 5P 축 | 조선업 어휘 | 대표 변수 |
|---|---|---|
| 성과(Y) | 생산성과 | 공수효율, 완성블록수, 재작업률, 납기지연일 |
| 운영(X1) | 공정운영 | 작업인원수, 용접장가동시간, 크레인가동률, 야드점유율, 잔업시간 |
| 투자(X2) | 설비투자 | 자동용접비율, 크레인점검횟수, 안전교육시간, 예방정비 |
| 신호(X3) | 품질신호 | 용접결함률, NDT불합격건수, 치수오차, 안전사고건수 |
| 환경(X4) | 환경외부 | 기온, 풍속, 강수, 협력사인력수급률, 강재입고지연일 |
