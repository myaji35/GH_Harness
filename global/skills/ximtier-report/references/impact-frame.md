# 비즈니스 임팩트 산정 프레임


**산식(고정)** — 공수효율 `e = 계획공수/실적공수`. `e→e′` 개선 시 동일 물량 실적공수 절감률 = `1 − e/e′`.

1. 절감공수 = 연간 실적공수 `H` × `(1 − e/e′)`
2. 직접 절감액 = 절감공수 × 시수당 종합원가 `c`(직접임금+간접+경비)
3. 부수효과(별도 행): 재작업 자재·검사비, 납기지연→지체상금 — 전부 `[고객 데이터로 대체]`
4. 투자 = 처방 이행 비용(자동용접 +Δ%p ⇒ 필요 설비 = 연 용접공수×Δ÷대당 처리능력) — `[고객 데이터로 대체]`, 참고 단가는 `[가정]`
5. 회수기간 = 투자 ÷ 연 절감액. **시나리오 2행 필수**: 목표(+8%) / 실증 보수(+5.46%)

**조선업 실측 재료**: 합성 데이터 기준 연간 실적공수 **175,490시간** → 8% 향상 시 **12,999시간 절감**(카드 산출 실측, Opus 검산 오차 0). 시수당 노무비는 **데이터에 없음** → 반드시 `[가정]` 라벨.
예: `c=55,000원 [가정]` 적용 시 연 절감 약 **7.15억 원**, 보수(+5.46%) 시나리오 약 **5.00억 원**. 숫자는 산업·고객마다 교체, 템플릿에 싣는 것은 **산식과 라벨 규율**.
