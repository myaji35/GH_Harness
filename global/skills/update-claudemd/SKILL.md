# CLAUDE.md 업데이트

## 핵심 원칙

대화에서 **확정된 것**만, **중복 없이**, **맞는 섹션에** 반영한다. 미확정 논의·구현 중인 것은 넣지 않는다(완료 후 반영). CLAUDE.md는 AI 통제 지침이지 회의록이 아니다.

## 절차

1. **결정 수집** — 이번 세션(또는 지정 범위)에서 확정된 것을 모은다:
   - 구조/설계 결정 (예: "제품은 독립 항목, 부서는 관점만")
   - 운영 함정·재발 방지 지식 (예: "재기동 시 X 초기화")
   - 완료된 이슈의 통제-relevant 결과 (DONE된 것만)
   - 새 규칙·금지사항
   - **제외**: 미확정 논의, 구현 중인 것, 코드가 이미 말하는 것, 일회성

2. **중복 확인** — 각 항목이 CLAUDE.md에 이미 있는지 `grep`으로 확인. 있으면 스킵 또는 갱신(예: "미해결"→"해소됨").

3. **섹션 배치** — 항목 성격에 맞는 섹션에:
   - 손대기 전 알아야 할 개념 → "핵심 개념"
   - 재발 방지 지식 → "운영 함정"
   - 작업 방식 규칙 → "작업 규칙"
   - 이슈 현황 → "미완 이슈"
   섹션이 없으면 새로 만든다.

4. **반영** — Edit로 해당 섹션에 추가. 날짜·근거(이슈 ID) 명기. 상대 날짜는 절대 날짜로.

5. **보고 후 커밋** — 무엇을 넣고/스킵했는지 표로 보고 → 커밋+push (`docs:` 접두).

## 자가 점검 (반영 전)

- "이건 확정인가, 아직 논의 중인가?" → 논의 중이면 넣지 않는다
- "이미 CLAUDE.md에 있나?" → 있으면 중복 금지
- "코드/README가 이미 말하나?" → 그러면 불필요 (단 통제 규칙은 예외)
- "이 프로젝트 CLAUDE.md인가 전역인가?" → 프로젝트 결정은 프로젝트 CLAUDE.md에

## 흔한 실수

| 실수 | 교정 |
|------|------|
| 대화 전체를 회의록처럼 복붙 | 확정된 결정만 압축 |
| 구현 중인 기능을 완료처럼 기재 | DONE된 것만, 진행 중은 "미완 이슈"에 |
| 이미 있는 내용 재추가 | grep으로 중복 확인 먼저 |
| 아무 섹션에 몰아넣기 | 성격 맞는 섹션에 배치 |
| 커밋 안 하고 끝냄 | 항상 docs: 커밋 + push |
