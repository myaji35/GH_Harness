# NPL 물건지 상권분석 · 자산평가 보고서 스킬

부동산 담보물건(주소/지번/건물명)을 입력하면 **상권분석 + NPL 자산평가 보고서(PDF)**를 생성한다.
전 과정 **VWorld 무료 API** 기반이며, 실거래·경매·감정가는 유료/별도키 항목으로 명확히 구분해 보고한다.

## 언제 쓰나
- "상권분석 해줘 / NPL 자산평가 / 물건지 분석 / 감정가 조사 / 이 물건 보고서 만들어"
- 지번 목록 또는 건물명이 주어지고, 입지·가격·규제·위치도를 담은 검토 자료가 필요할 때

## 산출물
- `상권분석/{물건명}_상권분석_NPL평가_{YYMMDD}.pdf` (최종)
- `상권분석/samples/{물건명}_1원거리.png · _2중거리.png · _3클로즈업.png` (위치도)
- `상권분석/data/{물건명}.json` (수집 원자료)

## 실행 절차

### 0. 준비
- 작업 프로젝트 루트 아래 `상권분석/`(없으면 생성), `상권분석/samples`, `상권분석/data`.
- 스크립트는 이 스킬의 `scripts/`에 있음. 프로젝트로 복사하거나 절대경로로 실행.
- `python3 -c "import PIL"` 확인, 없으면 `pip3 install Pillow`.

### 1. 주소 해석 (건물명만 있을 때)
지번을 모르고 **건물명만** 있으면:
1. `WebSearch`로 `"<건물명> 분양 주소 지번"` 검색 → 기사/분양페이지에서 **도로명 또는 지번** 추출.
2. `scripts/resolve_address.py --verify-road "<도로명>"` (또는 `--verify-parcel`)로 VWorld 검증.
   - `ok:true` + 좌표 반환되면 확정. 건물명과 프로젝트명이 다르면 **불확실성을 보고서에 명기**.
- 예: "강남 헤븐리치 더 시그니처" → 검색 → 강남대로 302 = 역삼동 837-10 (검증 완료).

### 2. 데이터 수집 (무료)
```bash
python3 scripts/collect.py "서울특별시 강남구 청담동 49-8" --json 상권분석/data/청담_49-8.json
```
수집 항목(전부 무료): 정제주소, 좌표(x,y), PNU, 지목·면적·소유, **공시지가 시계열**, 용도지역·규제.
- ⚠️ 지오코딩 지번과 토지대장 소재지가 다를 수 있음(행정/법정동 경계). refined 주소를 신뢰하고 **불일치 시 등기부 확인 권고**를 명기.

### 3. 3단 위치도 생성 (무료)
```bash
python3 scripts/make_map.py <x> <y> "청담_49-8" "물건지 · 논현동 49-8" 상권분석/samples
```
→ 원거리(zoom14·광역)·중거리(zoom17·상권+지적도+마커)·클로즈업(zoom18·필지형상) 3장.
- 클로즈업 zoom19는 VWorld Static Map 한계로 실패 → **zoom18 사용**(고정).

### 4. 보고서 HTML → PDF
- `assets/report_template.html`을 복제해 수집 데이터·이미지 경로·감정가 추정치를 채운다.
- **감정가 추정** = 최신 공시지가 × 현실화율(1.5~2.0) × 면적 (스크리닝용, 정식감정 대체 아님).
- **PDF 변환은 Chrome headless** (한글 겹침 방지):
```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="상권분석/{물건명}_상권분석_NPL평가_{YYMMDD}.pdf" "file://{절대경로 html}"
```
- 생성 후 표지 PNG 추출(`sips`)로 백지 아님 확인 → `open`.

## 평가 프레임워크 (보고서 필수 포함)

### NPL 자산평가 — 감정평가 3방식
| 방식 | 개념 | 적용 |
|---|---|---|
| 원가법 | 재조달원가−감가 (+토지) | 건물비중 큰 물건 |
| 거래사례비교 | 인근 실거래·경매 비교보정 | 대지·상가 |
| 수익환원 | NOI ÷ Cap Rate | 임대수익형 |

`NPL 회수가치(RV) = 감정가 × 낙찰가율 − (선순위+비용)` / `매입적정가 = RV × (1−목표수익률)`

### 4단 밸류에이션
공시지가(무료·하한) → 추정 감정가(공시×현실화율) → 실거래가(별도키·시세검증) → 경매 낙찰가율(유료·회수).

## 무료/유료 데이터 경계 (보고서에 명시)
| 항목 | 비용 | 소스 |
|---|---|---|
| 지번·지목·면적·소유 | 무료 | VWorld 토지대장 |
| 공시지가 시계열 | 무료 | VWorld |
| 용도지역·규제 | 무료 | VWorld 토지이용계획 |
| 지적도·배경지도·좌표 | 무료 | VWorld WMS/StaticMap/지오코더 |
| 실거래가 | 무료(별도키) | 공공데이터포털 국토부 |
| 상권 유동인구·업종 | 무료(별도키) | 소상공인진흥공단 |
| 경매 감정가·낙찰가율 | 유료 | 지지옥션·굿옥션 |
| 정식 감정평가 | 유료 | 감정평가법인 |

## 향후 확장 (미구현·옵션)
- **로드뷰/물건지 사진**: chrome 자동화(claude-in-chrome)로 카카오/네이버 로드뷰 좌표 URL 접속→파노라마 캡처. 느리고 불안정하므로 실패 시 건너뛰고 위치도만으로 완성. 이용약관(상업적 재배포) 확인 필요.
- 집합건물(오피스텔): 토지 아닌 **호실별 실거래·수익환원법** 중심 별도 템플릿.
