# 장애인 표준사업장 부지 적정성 평가 스킬

부동산 부지(지번 목록/주소)를 입력하면 **장애인 표준사업장(스마트팜·컨소시엄형·자회사형) 입지로서의 적정성**을 5대 축으로 평가하고 **PDF 종합보고서**를 생성한다. 전 과정 **VWorld 무료 API + 공개 DEM + 거리기반 통근 추정**으로 진행하며, 유료·현장확인 항목은 명확히 구분한다.

이 스킬은 `npl-property-analysis`(시세감정)를 **부지 적정성 판단으로 확장**한 것이다. 시세만 필요하면 그 스킬을, 표준사업장 입지 판단이 필요하면 이 스킬을 쓴다.

## 언제 쓰나
- "이 부지 표준사업장으로 적정한가 / 부지 적정 평가 / 스마트팜 입지 검토 / 통근버스 운행조건 검토"
- 장애인 고용 사업장(표준사업장·보호작업장·직업재활)의 부지 후보를 비교·판정할 때
- 특히 **발달장애인 통근 가능성**이 사업 성패를 좌우하는 경우

## 산출물
- `상권분석/{물건명}/{물건명}_표준사업장_적정성평가_{YYMMDD}.pdf` (최종)
- `상권분석/{물건명}/samples/` : 위치도 3단 + 필지 폴리곤 + (임야 시) 경사·표고도
- `상권분석/{물건명}/data/` : 수집 원자료 JSON

## 핵심 원칙 (이 스킬의 정체성)

### ⭐ 표준사업장 부지의 제1원칙 = "채용풀에서 통근 가능한 거리"
장애인 표준사업장은 **장애인 10인 이상 + 상시 30%↑**를 실제 고용해야 인증된다.
→ **부지가 발달장애인 거주지에서 통근 불가능하면 인원을 못 채워 사업이 성립 안 됨.**
→ 원거리 부지는 **기숙사 CAPEX(수십억)를 강제로 떠안는 구조**(괴산 누리팜 사례의 교훈).
→ **"부지 먼저 정하고 사람 모으기"가 아니라 "채용풀 반경 안에 부지 잡기"가 정답.**

### ⭐ 발달장애인 통근 기준은 일반인보다 엄격
- 장시간 차내 대기가 인지·정서 부담(이상행동·거부 유발), 보호자 안심 필요.
- **일반 근로자 60~90분 기준 적용 금지. 편도 40분을 부담선으로.**
- 두 가지 운행방식을 반드시 비교:
  - **A. 도어투도어 순회 픽업** — 표정속도 33km/h + 거주지 순회 픽업 12분. 대개 원거리에서 부적합.
  - **B. 역 집결 + 전용 승합차 2단 셔틀(권장)** — [거주지→집결역: 각자/보호자] + [집결역→부지: 근로지원사 동승 무정차 승합차]. 순수 차내시간만 계산하므로 부담 최소.
- 승합차 운행조건: 휠체어리프트·안전벨트 차량 / **근로지원사 1인 필수 동승** / 정시 고정 배차 / 역→부지 무정차 30분 내외.

## 실행 절차

### 0. 준비
- `상권분석/{물건명}/`(없으면 생성), `samples`, `data`.
- `npl-property-analysis` 스킬의 `scripts/`(collect.py, make_map.py) 재사용.
- `python3 -c "import PIL"` 확인.
- **VWorld NED API 호출 시 반드시 `domain=localhost` 파라미터 추가** — 없으면 INCORRECT_KEY. (조남동 사례에서 확인된 함정)
- **부번 필지는 지오코더가 본번으로 접으므로, PNU를 직접 구성**해 조회: `법정동코드(10) + 필지구분(1=일반/2=산) + 본번(4) + 부번(4)`.

### 1. 부지 데이터 수집 (무료)
필지별 지목·면적·소유·공시지가·용도지역을 PNU 직접조회로 수집(references/data-collection.md 참조).
- 지목 확인 필수: **답(畓)/전(田)이면 농지전용, 임야면 산지전용** 부담 발생.
- 용도지역: 계획관리(건폐율 40%, Best) > 생산관리(20%) > 제1종주거 등. 규제(토지거래허가·군사보호·학교보호·산지·시설저촉) 전부 수집.

### 2. 위치도 + 필지 폴리곤 (무료)
- `make_map.py`로 3단 위치도(원거리·중거리·클로즈업).
- 인접필지는 **지적경계 WFS(LP_PA_CBND_BUBUN)로 폴리곤 통합도** 1장(빨간 외곽 테두리 + 개별 파란 필지 + 중심 큰 점 + 지번·면적 라벨). references/polygon-map.md.

### 3. 통근 적정성 분석 ⭐ (이 스킬의 핵심)
- 부지 좌표 ↔ 채용풀 거주지(사용자가 지정, 예: 일산·양주·의정부) 하버사인 거리 → 추정 주행거리(×1.35~1.4).
- **방식 A(도어투도어)**와 **방식 B(역집결 2단셔틀)** 각각 편도시간 산출 → 40분 기준 판정표.
- 집결역 후보의 철도 접근성(1호선·GTX 등) + 기존 시내버스 직결노선 WebSearch로 확인.
- references/commute-analysis.md에 계산식.

### 4. (임야 포함 시) 경사·개발부담 분석 ⭐
- 임야 필지 경계 bbox에 ~25m 격자 → 폴리곤 내부점만 **공개 DEM(opentopodata SRTM 30m, `https://api.opentopodata.org/v1/srtm30m`)** 배치 조회(90점/req, 1.1초 rate limit).
- 인접격자 경사도 계산 → 평균·중앙·최대, 경사구간 분포(0-10/10-20/20-30/30+).
- **산지전용 기준 평균 25°**: 이하면 전용가능권. 경사 20° 미만이 개발가능부.
- 경사·표고 히트맵(초록 저지→빨강 고지) + 임야 폴리곤 오버레이.
- 개발부담 추정: 대지조성비(개발가능평 × 평당 30~60만) + 대체산림자원조성비(준보전산지 약 8,300원/㎡). references/slope-development.md.

### 5. 시세·감정 (npl-property-analysis 방식)
- 공시지가 총액 → 추정감정가(현실화율 1.5~2.0) → (사용자 제시단가 있으면) 비교표.
- **시세감정 대비 제시가격 비교표**: 공시/제시단가/추정감정 하한·중앙·상한을 나란히, 공시 대비 배수 표기.

### 6. 5대 축 종합 판정 + PDF
- `assets/report_template.html` 복제 → 5대 축(①물리조건 ②표준사업장 요건 ③통근 ④개발부담 ⑤시세) 각 ○/△/🔴 판정.
- **Chrome headless로 PDF** (한글 겹침 방지):
```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="{출력}.pdf" "file://{절대경로 html}"
```
- 검증: 표지 PNG(sips) 백지 아님 + 본문(pdftoppm) 한글 겹침 없음.

## 5대 평가 축 (보고서 필수)
| 축 | 판정 기준 |
|---|---|
| ① 부지 물리조건 | 면적·지목·형상·평탄도. 취락 평탄부 vs 임야 경사부 분리 |
| ② 표준사업장 요건 | 용도지역(계획관리 Best), 편의시설·생활인프라(학교·관공서 인접 가점) |
| ③ 통근 적정성 ⭐ | 발달장애인 편도 40분. 2단 셔틀로 성립하는지, 채용풀 범위 |
| ④ 개발부담 | 임야 경사·조성비·산림/농지전용부담금, 도시계획시설 저촉 |
| ⑤ 시세·감정 | 공시·추정감정·제시단가 비교, 개발부담 합산 판단 |

## 표준사업장 요건 (판정 기준값 · KEAD)
- 장애인 **10인 이상 + 상시 30%↑**, 중증비율(100명↓ 15% 등), 최저임금 이상, 편의시설.
- 무상지원: 일반 15억 / 컨소시엄·공동출자 20억. **토지구입비·임차보증금 제외**(시설·편의만).
- 자회사형: 모회사 50% 초과 지배 → 모회사 고용의무 산입. 컨소시엄형: 지자체+민간 공동출자.
- ⚠️ 정책단가·지원율 변동 → 진행 시 공단(1588-1519) 최신 기준 재확인.
