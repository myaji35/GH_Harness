# 임야 경사·개발부담 분석 (공개 DEM)

임야 필지가 있으면 경사도 분석으로 개발부담(조성·토목)을 스크리닝한다.
`scripts/slope_sample.py` → `slope_calc.py` → `slope_map.py` 순으로 실행.

## DEM 소스 (무료)
- **opentopodata SRTM 30m**: `https://api.opentopodata.org/v1/srtm30m?locations=lat,lng|lat,lng`
  - 배치 최대 ~90점/요청, **rate limit 1.1초 sleep 필수**.
- 대안: open-elevation `https://api.open-elevation.com/api/v1/lookup?locations=lat,lng`
- ⚠️ 30m 해상도 → 정밀측량 아님, **스크리닝(평균경사·구간비율)용**임을 보고서에 명시.

## 절차
1. **경계 조회**: 임야 PNU로 WFS GetFeature → geometry.coordinates(폴리곤 rings).
2. **격자 샘플**: bbox에 ~25m 격자(0.000225도) → point-in-polygon으로 내부점만.
3. **표고 수집**: 격자점 배치로 DEM 조회.
4. **경사 계산**: 인접 격자(동·북) 간 `atan2(고저차, 격자실거리m)` → 도(°).
5. **통계**: 평균·중앙·최대, 구간분포(0-10/10-20/20-30/30+).

## 판정 기준
- **산지관리법 전용 기준: 평균경사 25° 이하** → 전용 가능권.
- **경사 20° 미만 = 개발가능부**, 20°+ = 개발곤란부.
- 고저차 큰 동고서저/급사면이면 절·성토·옹벽 부담 커짐.

## 개발부담 추정 (스크리닝)
```
대지조성비 = 개발가능부(평) × 평당 30만(완만) ~ 60만(경사보정)
대체산림자원조성비 = 전용면적(㎡) × [고시단가 + 개별공시지가×1%]
  준보전산지 2025~2026 약 8,090원/㎡ + 공시×1%
농지전용부담금(답·전) = 개별공시지가 × 30% (상한 5만원/㎡)
```
- 도시계획시설(공원·학교·청사) 저촉 필지는 개발 자체 제한 → 저촉 시 "존치·보상" 시나리오 권고.

## 시각화 (slope_map.py)
- VWorld GRAPHIC 배경(zoom17~18) + 임야 폴리곤(굵은 초록 테두리).
- 표고 히트맵: 저지 초록 → 중간 노랑 → 고지 빨강.
- 헤더에 평균경사·표고범위·고저차, 우하단 범례.

## 법원리 산40 사례 결과
- 표고 62~142m(고저차 80m), 평균 13.2°, 최대 29.3°.
- 완경사 39% / 보통 38% / 급경사 22% / 험준 0%.
- 개발가능부 78%(약 10,194평), 개발부담 조성+산림전용 33~64억.
- 동측 급경사 고지 + 도시계획시설 저촉 → 초기개발은 취락 평탄부 중심 권고.
