# 통근 적정성 분석 (발달장애인 통근버스 운행조건)

## 원칙
- 발달장애인 **편도 40분**을 부담선으로 (일반 근로자 60~90분 기준 적용 금지).
- 반드시 **두 방식 비교**: A(도어투도어 순회 픽업), B(역 집결 2단 셔틀).

## 방식 A — 도어투도어 순회 픽업
```
편도(분) = (주행거리km / 표정속도 33km/h) × 60 + 순회픽업 12분
```
- 표정속도 33km/h: 국도/지방도 + 시내 정차 보수적 가정.
- 순회 픽업 12분: 거주지 내 여러 근로자 도어투도어 승차.
- 대개 20km 넘으면 40분 초과 → 원거리 부적합.

## 방식 B — 역 집결 + 전용 승합차 2단 셔틀 (권장)
```
[1구간] 거주지 → 집결역 : 각자/보호자 (지하철·시내버스)
[2구간] 집결역 → 부지  : 회사 전용 승합차 무정차
2구간 차내(분) = (주행거리km / 표정속도 48km/h) × 60
  (표정속도 48km/h: 시외 국도 위주, 신호 적음)
```
- 판정: 2구간 ≤30분 우수 / ≤40분 양호 / >40분 부담.
- 집결역 선정: 철도 접근성(1호선·GTX) + 기존 시내버스 직결노선(WebSearch로 확인) + 2구간 차내시간 최소.

## 승합차 운행조건 (필수 설계)
- 차량: 카운티/스타렉스급 + 휠체어리프트·안전벨트 (편의증진법).
- **근로지원사/생활관리사 1인 필수 동승** (차내 안전관리).
- 배차: 집결역별 출근 1회·퇴근 1회, 정시 고정 (예측가능성).
- 목표: 역→부지 무정차 30분 내외.

## 거리 계산 (하버사인)
```python
import math
def hav(lat1,lon1,lat2,lon2):
    R=6371; p1,p2=math.radians(lat1),math.radians(lat2)
    dp=math.radians(lat2-lat1); dl=math.radians(lon2-lon1)
    a=math.sin(dp/2)**2+math.cos(p1)*math.cos(p2)*math.sin(dl/2)**2
    return R*2*math.asin(math.sqrt(a))
# 추정 주행거리 = 직선거리 × 1.35~1.4
```
