# 누리팜 작물 판정 함수

**목적**: 작물 하나를 넣으면 `셀당 공헌이익 / BEP 배수 / 판정 / 탈락사유`가 나오게 한다.
전수조사 시 이 절차를 품목마다 반복한다.

## 🔴 절대 규율 — 병풀 15만원이 무너진 이유

> **BEP를 목표로 두고 역산하지 마라.** 그게 "kg 15만원"이 태어난 방식이다.
> **실거래 단가를 먼저 확정하고, 거기서 셀당 매출을 도출하라.** 결과가 미달이면 미달이라고 하라.

- 단가는 **복수 출처**로 확인한다. 단일 출처면 그 사실을 명시한다.
- **소매가로 도매를 역산하지 마라** — 와사비잎이 이 오류로 오판됐다(소매 25,000원의 50%라 추정 → 실제 벌크 4,807원).
- 확인 불가는 **✗로 명시**한다. 추정으로 빈칸을 채우면 정교하게 틀린 답이 나온다.
- **7월말·한파기 경락가를 연평균으로 쓰지 마라.** 양상추 실측이 증거다(여름 2,500 / 겨울 750 = 3.3배).

## 1단계 — 5분 스크리닝 (여기서 대부분 걸린다)

| # | 필터 | 탈락 시 |
|---|---|---|
| 1 | **노지 대량 산지가 있는가** | ❌ 수직농장 원가가 못 따라간다 |
| 2 | **kg 단가가 BEP 역산 수준인가** | ❌ |

실증: 병풀(마다가스카르 600톤 $13.3/kg)·카렌듈라(이집트 MOQ 5MT, 23,900원)·홀리바질(인도 $4.41/kg) — **셋 다 필터 1에서 걸렸을 작물**인데 관문 5개를 다 돌았다.

## 2단계 — 물리 제약 (누리셀 구조)

| # | 제약 | 기준 | 탈락 사례 |
|---|---|---|---|
| 1 | **환경대** | leaf 18~20℃ / herb 20~24℃ / cica 22~26℃<br>PAR 200~400 (정본 `assets.json`) | 와사비 12~15℃ → **동 전용화 필요 = 예측재배 유연성 상실** |
| 2 | **초장** | 원통형 ≤35cm / 평판 1단 ≤150cm | 홀리바질 85~88cm |
| 3 | **수확 방식** | 🔴 **카트리지 단위 일괄**이어야 함 | 카렌듈라(꽃 낱개)·깻잎(잎 낱장)·고추(익는 대로) |
| 4 | **셀 점유 기간** | 짧을수록 예측재배 유리 | 고추 8개월 |
| 5 | 뿌리 수확 | 원통형 불가 / **평판형은 가능** | 새싹삼은 평판 3단으로 부활 |

**셀 단위 단일 식재**다. 한 셀에 여러 작물 카트리지를 섞지 않는다(환경 제어 불가).

## 3단계 — 셀당 공헌이익 산출

```
셀당 주수 = 카트리지 구수(3~6) × 32          [원통형]
          = 재식밀도(주/㎡) × 단수(1~3)       [평판형 1,000×1,000]

셀당 월매출 = 셀당주수 × 포기중량(g) ÷ 1000 × kg단가 × (30 ÷ 작기일)
공헌이익    = 셀당월매출 − 변동비(종자·묘 등)
판정        = 공헌이익 ÷ BEP
```

**🔴 BEP = 26,680원** (4·5동 한계원가)
- 셀 감가 25,000 (300만 ÷ **10년** ÷ 12) + 건축 감가 1,680
- **인건비 0** — 40명은 5동 전제 고정비라 1~3동이 이미 부담한다. 4·5동에 다시 얹으면 **이중계상**이다.
- 1~3동 판정 시에는 **125,272원** (인건비 98,592 포함)

**산식을 반드시 보여라.** "무엇을 무엇으로 나눴는지" 안 보이면 무효다.

## 4단계 — 탈락 유형 분류

| 유형 | 사례 |
|---|---|
| 주수 부족 | 고추 8주/㎡ (상추 176주의 1/22) |
| 중량 부족 | 깻잎 잎 1g → 3단에도 월 2.88kg |
| 단가 부족 | 카렌듈라(BEP 0.18)·어성초 |
| 수확방식 불일치 | 카렌듈라·깻잎·고추 |
| 셀 점유 과다 | 고추 8개월 |
| 초장 초과 | 홀리바질 |
| **계절성 역행** | 고추·깻잎 = **겨울 강세**. 엽채는 여름에 노지가 죽어 우리가 이기는데 이들은 반대 |

## 5단계 — 사업 목적 기준 (여기를 빠뜨리지 마라)

수익성만 보면 안 된다. **1,000명 고용이 목적이고 작물은 수단**이다.

| 기준 | 질문 |
|---|---|
| 1. 수익성 | 공헌이익이 BEP를 넘는가 |
| 2. 확장성 | **25지점(62,000셀)** 해도 시장이 받는가 |
| 3. **고용 흡수력** | 가공 단계가 있는가 / **연계고용 구매기업 모수**가 큰가 |

- 🔴 **약용작물은 25배에서 전부 걸린다**(병풀 312%·어성초 379%). **식자재는 안 걸린다** — 식자재 유통 55조 대비 1,000명 규모가 0.27%.
- 🔴 **허브는 마진 좋으나 고용을 못 만든다**(생잎 판매 = 세척·포장뿐). 상추·새싹삼은 가공 단계가 있다.
- **연계고용**: 도급액 50% & 부담금 90% 한도. 품목 제한 조항 **없음**. 급식·외식은 구매기업 모수가 화장품사보다 자릿수 크다.

## 시장조사 시 함정 (실제로 3번 걸렸다)

**시장조사기관 수치는 라벨을 믿지 마라.**
- 병풀: GVR "$750.3M"은 **완제품**인데 원료로 인용됐다. 실제 원료는 20~60억
- 어성초: "32억 달러" → 실제 원료 **USD 90~150M** (20~35배 과대)
- 카렌듈라: 5개 기관이 같은 "extract market" 라벨로 **$58M ~ $46,595M (800배 편차)**

**우회로**: **UN Comtrade로 상위 카테고리 천장을 확인**하라. 홀리바질은 이 방법으로 판정났다 — HS 121190 잔여 바스켓, 인도 전체 $535M/121,410톤 = **$4.41/kg**.
※ 병풀·툴시·아슈와간다·로디올라는 **세계 어느 HS코드에도 없다.**

## 판정 결과 출력 형식

```
[작물명]
1차 스크리닝  : 통과 / ❌(사유)
물리 제약     : 환경대 leaf|herb|cica / 초장 Xcm / 수확 일괄여부 / 점유 X일
셀당 주수     : X구 × 32 = X주   또는   X주/㎡ × X단 = X주
산식          : X주 × Xg ÷ 1000 × X원/kg × (30÷X일) = X원
변동비        : X원 (사유)
공헌이익      : X원  → BEP 26,680 대비 X.X배
사업목적 기준 : 확장성 / 고용흡수력
판정          : ✅ / ⚠️조건부 / ❌(탈락유형)
미확인(✗)     : 
```
