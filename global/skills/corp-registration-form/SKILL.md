# /corp-registration-form

주식회사 설립 등기신청서를 정관과 보조 서류로부터 자동 작성한다.
원본 등기 양식을 가감 없이 재현한 뒤(→ `gov-form-html-builder` 활용), 정관의 확정값으로 ①~⑳ 항목을 채운다.

## 적용 범위

- **발기설립**(발기인이 주식 전부 인수) 기준. 모집설립은 별도.
- 자본금 10억 원 미만 소규모/1인 회사에 최적화(공증 면제·감사 미선임·이사회 미구성 자동 처리).
- 한국 상법·등기 양식 기준.

## ⚠️ 가장 중요한 교훈 — 정관 버전 관리

> **이번 작업 최대 시행착오: 구버전 정관(0609)을 보고 자본금·주식수를 전부 틀리게 기입 → 최신 정관(0624)으로 전면 재작업.**

**시작 전 필수 체크:**
1. 폴더의 정관/등기서류 PDF를 **수정일(ls -lat) 기준 최신순** 정렬
2. 동일 항목(자본금·1주금액·발행주식수·목적)이 **여러 버전에 다르게** 있으면 → **반드시 사용자에게 어느 것이 확정인지 확인**. 조용히 최신을 가정하지 말 것.
3. 정관 표지/요약의 핵심 수치(자본금 = 1주금액 × 발행주식수)를 **검산**해 정합성 확인.

## 워크플로우

### STEP 1 — 자료 수집 및 최신본 확정
```bash
ls -lat <프로젝트폴더>/*.pdf   # 수정일 최신순
```
- 정관 전문, 등기양식, 보조서류(임차계약서·등록면허세 납부서·등기수수료 영수증·위임장) 식별
- **버전 충돌 시 사용자 확인** (위 교훈)

### STEP 2 — 정관에서 확정값 추출
정관 PDF를 읽어(`Read` with pages) 다음을 추출:

| 등기 항목 | 정관 출처 | 비고 |
|----------|----------|------|
| ③상호 | 제1조 | "주식회사" 포함, 영문병기 가능 |
| ④본점 | 제3조 + 임차계약서 | 지번/도로명까지 정확히 |
| ⑤공고방법 | 제4조 | 전자공고 단독 시 신문단서 삭제. **"A 또는 B" 선택적 기재 금지** |
| ⑥1주 금액 | 제6조 | 100원 이상 |
| ⑦발행예정주식총수 | 발행할 주식 총수 조항 | 수권주식 |
| ⑧발행주식 총수·종류 | 설립 시 발행 조항 | 보통주/종류주 구분 |
| ⑨자본금 | 제5조 | = ⑥ × ⑧ (검산 필수) |
| ⑩목적 | 제2조 | 호별 전체 나열, "위 각 호 부수사업" 포함 |
| ⑪이사·감사 | 부칙 발기인 + 이사 조항 | **1인회사 판별** ↓ |
| ⑫대표이사 | 〃 | 성명·주민번호·주소 |

### STEP 3 — 1인 회사 / 소규모 자동 판별
- 발기인 1명 + 이사 1명 → **1인 회사**:
  - ⑪ 사내이사 1명(=대표이사), **감사 "해당없음"**
  - ⑬종류주식·⑭지점 없으면 "해당없음", ⑮존립기간 "없음"
  - ⑯기타: 정관에 주식양도 이사회승인 규정 있으면 → "이사회(이사회를 두지 아니하는 경우 주주총회)의 승인" 표기
  - **첨부서면 조사보고서**: "이사(대표이사)의 조사보고서 (감사 미선임)" — 감사·감사위원회 표기 금지
  - 이사회의사록·재산인도증·변태설립보고서·감정서 등 → 제출 안 함("통" 빈칸)
- ①등기의 목적: **"주식회사 설립(발기설립)"** — (발기설립) 누락 주의

### STEP 4 — 세액 (⑰⑱) 교차검증
> **교훈: 안내문 공식과 구청 산정값이 다를 수 있다. 실제 납부서/영수필확인서 금액이 절대 우선.**

- 등록면허세 납부서에서 **과세표준·등록면허세·지방교육세·전자납부번호** 추출
- 검산: 지방교육세 = 등록면허세 × 20/100 (정합 확인)
- 공식(과세표준 × 4/1000 × 3배[수도권])과 다르면 → **납부서 값을 신뢰**(감면·단수처리 반영된 확정액). 사용자에게 차이를 한 번 보고하되, 영수증 값으로 기입.
- ⑱과세표준액 = 자본금 총액 (납부서와 일치 확인)
- 등기신청수수료 영수증에서 납부번호 추출 → "등기신청수수료 납부번호"란

### STEP 5 — 신청인란(⑳) + 첨부서면
- 신청인 상호·본점, 대표이사 성명·주소·전화
- 대리인 신청 시: 대리인 성명·주소·전화 (주민번호는 위임장에, 신청서엔 성명·주소·전화만)
- 등기소: "○○지방법원 ○○등기소(국) 귀중" (본점 관할)
- 첨부서면: **제출 서면 = "1통"**, 해당없는 서면 = **"통"(빈칸)** — 사용자 확인된 규칙
- 알림서비스: 동의 시 성명·휴대전화(실제 알림 받을 대리인/대표)
- 일자: 사용자 지정일로 **전 항목 통일**(②사유의 발기인회 종료일 = ⑳신청일). 단 잔고증명 기준일·세금 납부일 등 **실제 발생일은 유지**.

### STEP 6 — HTML/PDF 산출
- 양식은 `gov-form-html-builder` 규칙으로 가감 없이 재현
- 빈양식/작성예시 토글 제공
- `pdf-to-print-pipeline`으로 PDF 출력

## 산출물
- `<상호>_설립등기신청서.html` (① 원본 / ② 빈양식 / ③ 작성방법 토글)
- `<상호>_설립등기신청서_최종.pdf`
- 미확정 항목(주민번호 뒷자리·신청일 월일·납부번호 등)은 빈칸 또는 노란색 todo 표시

## 자가 점검 체크리스트
- [ ] 정관 최신본 확인 + 버전 충돌 시 사용자 확인했는가
- [ ] 자본금 = 1주금액 × 발행주식수 검산 통과
- [ ] 1인 회사면 감사/이사회/조사보고서 주체 정확히 처리
- [ ] 세액은 납부서 실제값(공식 역산 아님)
- [ ] 첨부서면 제출분만 "1통", 나머지 "통"
- [ ] ①에 "(발기설립)" 포함, ⑤공고방법 신문 선택적기재 없음
- [ ] 전 일자 통일(실제 발생일 제외)
